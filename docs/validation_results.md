# Extended benchmark validation — 2026-09-15

This document records empirical validation evidence. It is **not** a normative methodological specification; accepted ADRs remain authoritative.

Validation was executed from `main` at commit `eb59ea4490d2c556d19ba74429a94803c84247eb` by GitHub Actions run `35020551271` (`extended benchmark validation`). The ordinary acceptance gate for the same commit also passed.

## Protocol

Three reproducible artifacts were generated:

```bash
python -m benchmarks.run_controlled_noisy --output results/controlled-noisy.json
python -m benchmarks.run_sampling_robustness --output results/sampling-robustness.json
python -m benchmarks.run_noisy_robustness --output results/noisy-robustness.json
```

The fixed-noise controlled reference uses `N=300`, sample seed `123`, observation seed `456`, and scale-relative `sigma=0.10` across all 13 controlled diagnostics.

The clean sampling study uses `N=300`, fixed MISDA seed `123`, `sigma=0`, and 20 independent sample seeds (`1001` through `1020`) for all 13 diagnostics.

The observation-noise study uses `N=300`, fixed MISDA seed `123`, five replicate seeds, and `sigma ∈ {0, 0.05, 0.10, 0.20, 0.40}`. Within each problem/replicate, clean `Z` and the standardized perturbation realization are reused across sigma so the curve varies only noise intensity. The focused set contains eight diagnostics: independence, total redundancy, four linear blocks, nonlinear monotonic redundancy, antagonistic linear groups, four nonlinear blocks, antagonistic nonlinear groups, and transitive chaining.

No sigma is treated as a scientific pass/fail threshold.

## Dimensional recovery

The fixed-noise `sigma=0.10` run recovers the declared latent and structural dimensions exactly for Cases 1–11. Cases 12 and 13 remain the already documented limitations: `transitive_chain` is reported as `UNSUPPORTED` with `TRANSITIVE_CHAINING`, and `regime_switching` as `UNSUPPORTED` with `HIDDEN_SPECTRAL_STRUCTURE`.

The 20-seed clean sampling study strengthens that conclusion. Cases 1–11 recover both dimensions in 100% of replicates and are `SUPPORTED` in 100%. Case 12 misses both declared dimensions in 100% of replicates while `TRANSITIVE_CHAINING` is detected in 100%; Case 13 likewise misses both dimensions in 100% while `HIDDEN_SPECTRAL_STRUCTURE` is detected in 100%.

In the observation-noise sweep, every regular focused diagnostic retains 100% exact latent and structural recovery at every tested sigma through `0.40`. `transitive_chain` remains a 0% dimensional-recovery case with `TRANSITIVE_CHAINING` detected in every replicate at every sigma.

At the highest tested noise (`sigma=0.40`), dimensional support becomes more cautious without changing the correct dimensions: `monotonic_redundancy` is `SUPPORTED` in 40% of replicates and reports `TRANSITIVE_CHAINING` in 60%; `antagonistic_nonlinear_groups` is `SUPPORTED` in 60% and reports `TRANSITIVE_CHAINING` in 40%. This is diagnostic evidence, not a correction rule.

## Pareto interpretation

The extended validation separates three different comparisons:

- observation agreement: sampled clean truth `P_Z` versus the observed full-space front `P_Y`;
- reduction agreement: `P_Y` versus the selected reduced-space front `P_R`;
- end-to-end agreement: `P_Z` versus `P_R`.

These distinctions are necessary because exact Pareto membership can be unstable even when dimensional recovery is exact.

### Case 6 — nonlinear monotonic redundancy

Clean objectives are twenty monotonic transforms of one generating variable. Under exact observation the sampled Pareto front is one point. Independent observation errors break the exact common ordering across the twenty objectives and inflate the observed full-space front before reduction.

At `sigma=0.10`, averaged over five replicates:

```text
latent recovery              1.0000
structural recovery          1.0000
observation Jaccard P_Y/P_Z  0.0260
reduction Jaccard P_R/P_Y    0.0260
end-to-end Jaccard P_R/P_Z   0.2000
observed front fraction      0.1300
additive epsilon+            0.1969
```

Thus the low exact-membership agreement is primarily observation-driven: the noisy 20-objective front expands from one clean optimum to many nondominated observations, while a one-objective reduction again has a single minimum. Which noisy minimum is retained need not be the clean optimum.

### Case 10 — antagonistic nonlinear groups

The clean problem contains two antagonistic monotonic families generated by `x` and `1-x`. The sampled clean front contains all rows. Across the entire tested noise grid, the observed full-space front also contains all rows: observation Jaccard remains `1.0`.

At `sigma=0.10`, averaged over five replicates:

```text
latent recovery              1.0000
structural recovery          1.0000
observation Jaccard P_Y/P_Z  1.0000
reduction Jaccard P_R/P_Y    0.1547
end-to-end Jaccard P_R/P_Z   0.1547
observed front fraction      1.0000
additive epsilon+            0.1178
```

Here the membership loss is reduction-driven, not observation-driven. Twenty independently perturbed objectives make the full space highly saturated, while retaining one representative from each antagonistic family produces a two-dimensional projection in which some observations dominate others.

The same qualitative effect occurs in `antagonistic_linear_groups`: dimensional recovery is exact across the noise grid, observation Jaccard remains `1.0`, while reduced-front exact membership decreases as noise increases.

## Consequence

No Pareto implementation bug is indicated by these results. The current implementation computes exact minimization nondominated row sets, and the observed-data Pareto-stability layer already exposes front saturation, dominance margins, and range-normalized additive epsilon in addition to exact set agreement.

The evidence reinforces the separation established by ADR 0014: dimensional support and Pareto stability answer different questions. A low Pareto Jaccard must not be interpreted by itself as evidence that the graph-derived dimension is wrong. Exact membership, observed-front saturation, and geometric approximation should be read together.

No estimator change or fixed Pareto-stability threshold is justified by this validation run.
