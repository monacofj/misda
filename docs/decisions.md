# MISDA decision summary

The authoritative architectural and methodological specification of MISDA is now maintained as Architecture Decision Records in [`docs/adr/`](adr/README.md).

This file is intentionally no longer an independent normative ledger. When this summary, older design notes, comments, tests, notebooks, or implementation details conflict with an accepted ADR, the ADR is authoritative unless a later ADR explicitly supersedes it.

The ADR set is designed to be sufficient for an independent reimplementation of MISDA and to act as a regression barrier for future refactors and performance optimizations. It records the method, formal definitions, public architecture, current implementation choices where relevant, permitted implementation freedom, forbidden shortcuts, and verification expectations.

See the [ADR index](adr/README.md) for the complete specification.
